# Tadabbur (تدبر) — Quranic Reflection for iOS

A mindful iOS app designed to display inspiring Quranic verses (تدبر) throughout the day with authentic Uthmani script, beautiful audio recitations by **Sheikh Nasser Al-Qatami**, dynamic lock screen widgets, and smart auto-reflection automations.

---

## ✨ Features

- **📖 200 Curated Impactful Ayahs**: Authentic Uthmani calligraphy with diacritics / tashkeel and clear English translations.
- **🎙️ Sheikh Nasser Al-Qatami Recitation**: Seamless online streaming & offline disk caching (`EveryAyah` 128kbps) for instant, uninterrupted listening.
- **✨ Frosted Glassmorphism Audio Player**: Live sound equalizer wave animations, hairline progress bar, elapsed timer, and tactile haptic feedback.
- **📱 Lock Screen & StandBy Widgets**:
  - `accessoryRectangular` lock screen widget for at-a-glance reflection.
  - `systemLarge` home screen & iPad widget with futuristic mountain aurora aesthetics.
  - **40-Minute Auto-Rotation** to keep verses fresh all day.
- **🧙 Interactive Widget Setup Wizard**: Step-by-step visual in-app guide to easily place and customize the widget on your iPhone Lock Screen.
- **🔔 Configurable Daily Notifications**: 1 to 5 daily reminders, evenly spaced or custom times.

---

## 🛠️ Tech Stack & Requirements

- **Swift 5.9+ / SwiftUI**
- **iOS 16.0+** (optimized for iOS 17 & 18+)
- **WidgetKit & BackgroundTasks**
- **AVFoundation** (with `AVAudioSession` playback mode)

---

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/islamwell/tadabbur-ios.git
   cd tadabbur-ios
   ```
2. Open `Tadabbur.xcodeproj` in Xcode.
3. Select an iOS Simulator or connected iPhone and click **Run** (`Cmd + R`).
